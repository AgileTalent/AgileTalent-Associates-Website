# Client logo assets

The About and Careers scrolling marquees use the local image files in this folder. The public manifest, `logos.json`, contains filenames only; it does not hotlink to external image hosts.

## Organisations represented

- Eric Kayser
- Autochek
- NovaTrack
- Rytegate Technologies
- Shine Shine Cosmetics
- Hub360 Limited
- Fifth Ascendant Group

Algorism Limited and VDT Communications are intentionally excluded. Do not represent them as organisations AgileTalent has worked with.

## Adding an organisation

Upload its approved logo image into this folder and add its name and filename to `logos.json`. Both marquees will update automatically. Keep the logo proportions intact and the display size compact.
