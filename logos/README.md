# Client logo assets

The About and Careers scrolling marquees use local image files stored in this folder. The public `logos.json` manifest contains filenames only. The website does not hotlink to external image hosts, and image-source URLs are not stored in the site repository.

## Organisations represented

- Eric Kayser
- Autochek
- NovaTrack
- Rytegate Technologies
- Shine Shine Cosmetics
- Hub360 Limited
- Fifth Ascendant Group

Algorism Limited and VDT Communications are excluded and must not be represented as organisations AgileTalent has worked with.

## Logo availability

Local logo files are currently available for Eric Kayser, Autochek, Rytegate Technologies, Shine Shine Cosmetics, Hub360 Limited and Fifth Ascendant Group.

The NovaTrack image link supplied for download did not return a valid image file. NovaTrack is therefore not displayed in the carousel until its logo image is provided as an upload.

## Adding an organisation

Upload the approved logo image into this folder and add its name and filename to `logos.json`. Both marquees use the same manifest. Keep original logo proportions and display dimensions compact.
